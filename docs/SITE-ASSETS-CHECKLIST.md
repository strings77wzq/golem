# Site Asset Checklist

## Core assets (must have)

- Project logo (light/dark variants)
- Hero screenshot (CLI/TUI)
- Quickstart command screenshot
- Feature grid illustrations

## Demo assets (should have)

- Short terminal demo GIF (install -> init -> first response)
- RAG demo screenshot
- MCP demo screenshot
- Skills demo screenshot

## Proof assets (future)

- Benchmark chart image
- Showcase card thumbnails
- Release timeline graphic

## Asset quality requirements

- Keep command output readable
- Redact API keys and sensitive paths
- Use consistent terminal theme and font size
- Use WebP/PNG for docs images, GIF/MP4 for motion demos
