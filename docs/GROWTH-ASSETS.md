# Open-Source Growth Assets Plan

This document defines external assets required to increase adoption and conversion.

## Required assets

1. README hero + quick links + quickstart path
2. Project logo set (light/dark)
3. Feature badges and trust signals
4. Demo GIF/MP4 (first success, RAG, skills, MCP)
5. Release note template with install/update guidance
6. Showcase page structure

## Asset ownership

- Docs owner: markdown structure and consistency
- Product owner: workflow realism and value proof
- Release owner: changelog + artifact integrity

## Completion criteria

- New visitor can understand value and install path in under 60 seconds
- Demo media exists for at least 3 core workflows
- Release notes include actionable upgrade guidance
