# Retention Loops

This document identifies product loops that can turn first-time users into repeat users.

## Loop 1: Session continuity

- Trigger: user got first useful response
- Action: suggest `golem agent -C last`
- Reward: no context loss, less rework

## Loop 2: Progressive capability unlock

- Trigger: user completed one-shot flow
- Action: suggest RAG / Skills / MCP in sequence
- Reward: visible capability expansion without relearning basics

## Loop 3: Learning to contribution

- Trigger: user completed tutorials/labs
- Action: guide to contributing docs/templates/issues
- Reward: ownership and community participation

## Loop 4: Operational confidence

- Trigger: user worries about setup health
- Action: use `golem status` and troubleshooting ladder
- Reward: faster self-recovery and trust
