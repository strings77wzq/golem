# Community Channels Plan

## Primary channels

- GitHub Discussions for questions and idea exchange
- GitHub Issues for actionable bugs/features/docs requests
- Security advisory channel for vulnerability reports

## Contribution funnel

1. User starts from docs/quickstart
2. User solves a problem and checks tutorials
3. User reports feedback through templates
4. User contributes docs or code through PR template

## Feedback loop requirements

- Every issue template captures reproducible context
- PR template enforces tests/docs checklist
- Discussions link is visible in docs and README
