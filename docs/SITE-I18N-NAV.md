# Site Bilingual Navigation Strategy (EN/ZH)

## Principle

Keep the same information architecture across English and Simplified Chinese.

## Navigation parity

Primary nav entries:

1. Home
2. Quick Start
3. Tutorials
4. Architecture
5. Troubleshooting
6. Contributing

Each EN page should map to one ZH page with equivalent structure.

## URL strategy

- English default: `/...`
- Chinese mirror: `/zh/...`

Example:

- `/quickstart` <-> `/zh/quickstart`
- `/tutorials` <-> `/zh/tutorials`

## Content policy

- Commands remain identical in both languages
- Terminology glossary should be shared (provider, tool calling, session, gateway)
- If EN updates first, ZH should be marked as pending-sync with timestamp
