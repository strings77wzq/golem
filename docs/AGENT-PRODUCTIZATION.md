# Agent Productization Alignment

This document aligns agent behavior with first-run success and site/doc narratives.

## Productization goals

1. Reduce first-use cognitive load
2. Increase successful completion of practical tasks
3. Connect agent usage with docs/tutorial pathways

## Behavior alignment points

- First-run examples should map to real commands in quickstart and demo docs
- Post-success recommendations should map to tutorials and advanced workflows
- Session continuity should be highlighted as a retention mechanism

## Boundaries

- Keep core architecture constraints intact
- Do not introduce behavior that violates tool safety and layer boundaries
