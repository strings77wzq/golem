## Requirements
### Requirement: First-run experience creates an activation moment
The product SHALL provide one or more curated first-run experiences that quickly demonstrate meaningful user value.

#### Scenario: User completes first-run experience
- **WHEN** a user launches Golem for the first time
- **THEN** they SHALL be offered at least one guided or documented example that produces an immediately useful outcome

### Requirement: Reusable examples lower repeat-use friction
The project SHALL provide reusable prompts, sample configurations, or example scenarios that encourage repeat usage.

#### Scenario: User wants to try a second workflow
- **WHEN** a user completes an initial successful run
- **THEN** they SHALL be able to discover follow-up examples or templates without searching the repository manually

### Requirement: Retention hooks are visible
The project SHALL surface pathways that encourage continued exploration, including sessions, tutorials, showcases, or feature prompts.

#### Scenario: User considers next step after first success
- **WHEN** a user finishes the initial flow
- **THEN** the interface or documentation SHALL suggest at least one next-step path for continued usage
