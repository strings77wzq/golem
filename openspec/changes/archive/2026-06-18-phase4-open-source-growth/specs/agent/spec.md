## ADDED Requirements

### Requirement: Agent experience supports first-use activation
The product-facing agent experience SHALL support a first-use path that helps users reach a successful outcome quickly.

#### Scenario: User starts agent for the first time
- **WHEN** a new user launches the primary agent entrypoint without prior project familiarity
- **THEN** the surrounding product flow SHALL provide enough guidance, examples, or prompts to help them produce a successful first interaction

### Requirement: Agent experience exposes next-step exploration paths
The product-facing agent experience SHALL connect users from first success to additional workflows.

#### Scenario: User finishes a first successful interaction
- **WHEN** the user completes an initial useful session
- **THEN** the product experience SHALL make follow-up examples, workflows, or documentation paths discoverable
